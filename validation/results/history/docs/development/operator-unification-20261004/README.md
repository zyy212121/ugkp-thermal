# 测试库算子合并与验证记录（2026-10-04）

本轮仅在 `/home/lss/OpenFOAM/lss-10/applications/solvers/ugkp-thermal-test` 实施。生产 thermal / fluid 两库及 E 盘未同步。用户后来已解除效率测试禁令，本轮已补测；没有运行 k8，没有派发子智能体，没有修改生产计算进程。

## 修改范围

1. CHT 的颗粒体积分数、碰撞压力、碰撞弛豫时间接入公共算子；原 FP32 常数和 tiny 适配保留。
2. gas 的梯度面状态接入公共实现。面两侧选择统一使用 `oppositeCellAcrossFace`；周期边界面按实际 owner 访问约束验证。
3. FSH / CHT 壁面能量按面和通道归约共用一个设备计算体。shuffle 保留输入精度，账本始终 double，lane 顺序和原子发布规则保持。
4. 拖曳逆松弛率的主体共用，原 gas / thermal 数值边界以 `RegularizedDragInputs` / `BoundedDragInputs` 编译期策略保留。原公式系数、零滑移处理、截断及乘除顺序没有统一改值。
5. 无排序压力投影共用面增量、状态发布、发布后回读恢复速度和温度。更新后回读的舍入顺序保留，驻留 / 瞬态接触 / 沉积粒子约束继续保留；未合并或更改 launch。
6. coldWall1D 的组装和更新主体归并为一份 `.inl`，FP32 的缓存和稳定 PCR 策略保留。

上述六项的重复计算体已收拢。精度、物理约束和调度适配仍有必要差异；这份结论不等于证明仓库所有相似代码都能无条件再合并。没有新增工况经验系数，也没有更改 thermal L0/L1/L2 配置接口。

三应用入口源文件在本轮设备函数/引入点之外的代码比较均相同。源码补丁 `changes.patch` 从修改前快照生成，只包含本轮 23 个输入文件；不含原有 README 修改、不含原有 bentSRM 测试、不含刻意未复制的案例删除。

## 效率测量及边界

本机 GPU 为 NVIDIA GeForce RTX 4060 Laptop GPU，CUDA 13.1.115，编译目标 sm_89。两个通用低负载：512 / 1024 cells、65536 / 131072 particles。同一网格/输入/128 线程发射配置，各 **10 组**前后配对并交替 AB/BA；没有把它们命名为历史案例 k1/k2。FSH/CHT 探针含瞬态壁面粒子约束，没有针对无有限接触壁面的特殊情形优化。

初测为连续普通发射。短核可能受主机发射和设备时钟影响，因此另保留 CUDA Graph 复核，捕获同一批 64 次核发射，以减少主机供应间隙。两轮原始数据均保留，未删除低于 1 的样本。以下为 Graph 配对加速比中位数（旧耗时/新耗时）：
