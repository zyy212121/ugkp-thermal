共享常驻气体边界库审查说明

基线：da542a1e54c963ee5371f09a905001db743fcb95。
工作目录：pr29build/solver；案例位于相邻 case 目录。未改 README；未合并远端 PR。
本增量建立共享边界库并接入总条件入口。上一增量中的组分相关黏度/导热、温压相关扩散和非均匀喷气仍保留。

1. 架构与范围
common/gasBoundary/Definition.H 是唯一边界描述、物理角色和函数数据定义。
FoamInput.H 在初始化时把字段、非均匀值、函数表编译为描述；不在 RK 子阶段调用 OpenFOAM Function1。
Resident.cuh 是唯一设备配置所有者及现有 SoA 视图发布实现；Evaluate.H 和
common/operators/evaluateResidentBoundary.cuh 是共享数学及设备执行入口。
gasUGKP、gasUGKPSteady、CHT、CHMT 使用同一描述、所有者和算子。FSH 保留原有进程隔离方式，
启动时通过显式 Wire.H 编码传入同一库；没有另建应用私有数学实现。
CHMT 的旧物理 kind 转换移入共享 prescribed 接口，保留旧案例语义；应用仍负责物理角色配置。
CHMT 坐标变化保留边界程序、镜像和组分边界存储；没有在每次坐标更新时重新上传函数表。
拓扑/配置初始化与必要输出仍有主机通信。本次不宣称整个应用完全没有 Host↔Device 通信。

2. 支持的输入
保留原 fixedValue、zeroGradient、calculated、inletOutlet、noSlip、几何/周期及既有 wave 路径。
新增 totalPressure、totalTemperature、pressureInletOutletVelocity 的共享设备实现。
uniformFixedValue 支持 scalar/vector constant、线性 table/tableFile（clamp/repeat）；scalar polynomial。
pressureInletOutletVelocity 的可选 tangentialVelocity 支持 constant/table，设备上投影到切平面。
不宣称兼容所有 OpenFOAM 边界与 Function1 类型；未知函数及未实现组合由输入/应用校验拒绝。
旧 characteristic-total 模式、组分 wave/scheduled 模式原有的能力限制没有被绕过。
FSH 不支持 boundaryLayer 壁模型的原有应用级拒绝保留；其 lowRe 总条件入口烟测成功。
reactingSST boundaryLayer 与非零颗粒组合的既有应用级限制保留；本次颗粒测试使用 lowRe SST。
没有新建“无固体 CHT”等替代应用，也没有案例专用分支。

3. 数学
气体常数 R 使用该边界实际组分；保留字典指定的 pressure/temperature gamma。
以相对网格的法向速度判定流入。pressureInletOutletVelocity 在流入时保留内部法向速度，
使用指定切向速度；流出时外推。令 K=流入时 |U|²/2，流出时为零：
 T = T0 - K*(gammaT-1)/(gammaT*R)
 psi = 1/(R*T)
 p = p0/[1+psi*K*(gammaP-1)/gammaP]^[gammaP/(gammaP-1)] （psi 分支，gammaP>1）
 p = p0/(1+psi*K) （gammaP<=1 或无 psi 的密度形式联立 EOS）
 rho = p/(R*T)
这是总条件边界方程与 EOS 的同时解，不复制 OpenFOAM 某次滞后 psi 更新的中间值。
原生 OpenFOAM 边界类迭代收敛后与设备值相符。未截断总温或添加数值回退。
总量 p0/T0 只在不可变描述中保存；现有通量/梯度消费者读取求得的静态 p/T。
RK 子阶段传入对应物理时间；CUDA Graph 回放保留各时间节点偏移。
稳态采用既有 boundaryTime，避免以伪时间推进边界表。

4. 构建与验证
最终完整 ./Allwmake 退出 0，六个程序均来自本工作区：gasUGKP、gasUGKPSteady、FSH、
FSHCudaBackend、CHT、CHMT。构建用时 8:52.20；time 报告最大 RSS 1563388 KiB。
所有实际程序哈希见 binaries.sha256；构建日志见 evidence/build-final.log。

共享数学：960 组原方程/EOS/流向/切向速度核对；温度方程最大绝对残差 2.2737367544323206e-13 K。
原生 OpenFOAM 10：4 个入口面，与设备 U/p/T 输出逐值相同（本次打印精度下最大差 0）。
设备探针：257 面，constant/table/polynomial，100 次 Graph 回放；memcheck 0 errors、0 leaked bytes。
Nsight 实测 100 次 kernel 区间内 0 次 memcpy、0 字节传输；3 次配置 H2D 共 39192 字节，
最后一次验证 D2H 12336 字节。此结论针对共享库探针，不等同于完整应用零通信。

原生统一入口：gasUGKP 与 gasUGKPSteady 各 3 种入口；CHT、CHMT 各 legacy/constant/table；
另有 gas legacy/total 对照，全部运行成功。table 的瞬态最终写出温度 320 K，稳态 boundaryTime=0 为 300 K。
Euler、SSPRK2、SSPRK3 路径均运行；被核对案例的 rhoY_Air+rhoY_CO2-rho 最大绝对误差为 0。
4 个求解器 table 入口重启通过；非零颗粒的瞬态/稳态重启保持颗粒状态和 RNG/id，误差见结果 JSON。
封闭双相测试保留常比热、高温颗粒、非线性热容与阻力换热：质量/动量绝对误差 0，
最大能量误差 5.820766091346741e-11 J；100 步阻力换热测试三项误差均为 0。
原有 gasUGKP/CHT/CHMT 边界与 da542a1e 基线对照通过；CHMT 物理 checkpoint payload 位相同。
完整 gasUGKP 和 CHMT table 案例 memcheck 均 0 errors、0 leaked bytes。
额外 gas-wave、gas-single、CHMT moving-short 回归通过；CHMT 8 步表面退移保留重启、
常数输运与基线物理 payload 逐字节一致，并能从旧版 checkpoint 续算到相同状态。
这些结果见 regression-results.json；没有将 8 步称作 8 个独立案例。
CHMT 的原有 single-pass wall waveform/regime mismatch 警告仍保留；这些短案例用于接线、重启和数值回归，
不能据此宣称强耦合精度或 ARC3696 稳态收敛已经验收。

既有测试限制：旧 checkpoint/host-CUDA-shim 测试集合中 5 个失败在未改 da542a1e 上也同样复现，
另 3 个通过。两个失败引用工作区之外不存在的比较脚本，三个依赖不完整的旧 CUDA 主机替身。
对照原始日志均附带；未修改这些测试来掩盖失败。新 checkpoint 无原案例恢复测试通过。

5. 复现
在 OpenFOAM 10/CUDA 环境，从解包后的 solver 根目录：
 source /opt/openfoam10/etc/bashrc
 export FOAM_USER_APPBIN="$PWD/bin"
 ./Allwmake > build.log 2>&1
 bash validation/shared_boundary/run_native.sh /绝对路径/新输出目录

run_native.sh 使用仓库内 fixtures，不依赖旧案例目录。比较旧版需预先在
build-evidence/shared-boundary/baseline-bin 放置基线生产程序；缺少时明确跳过基线时间比较。
Nsight 可选：
 /usr/local/cuda/bin/nsys profile --trace=cuda --cuda-graph-trace=node -o trace 新输出目录/build/resident
 /usr/local/cuda/bin/nsys export --type sqlite -o trace.sqlite trace.nsys-rep
 python3 validation/shared_boundary/check_trace.py trace.sqlite transfers.json

6. 交付边界
本包是通用边界库及接口的审查包，不是三个 Mach 数、喷气/无喷气共六组 ARC3696 的最终稳态结果。
没有以短程启动耗时宣称端到端提速；完整原案例仍需另行完成网格/物性/入口一致性核对及收敛计算。
本次不关闭前序审查中与本增量无关的完整应用精度、重启输出或大规模性能限制。

独占 GPU、每项 5 对交替运行的短案例墙钟时间（含初始化和输出）：
