验证方法
pr_wall_regression.py 从现有 gas_state_probe.cpp 取得真实生产算子 include 集，
用 pr_wall_probe.inc 构造物理一致的状态，调用 gasFaceSubgridTransportProperties
及完整 computeRiemannGasFaceFluxDevice<true>。同一个测试体分别编译为主机
C++ 和原生 CUDA，CUDA 版本在 GPU 执行，不是主机适配器冒充 CUDA。
设备内存采用统一内存，仅用于测试夹具；生产实现没有增加分配或传输。

独立 Python 参考不调用 C++ 热壁函数：以给定 LinearCp 组分热容、理想混合气
R 和 Pr 公式计算物性；热壁函数匹配点使用二分法求解，计算导热系数和热流，
覆盖黏性区与对数区。在较高 k 的对数区按既有方程保留热壁函数的速度修正项。

六类配置，每类两种正湍动能 k=1e-12、0.1，共 12 个面状态：
0 常黏度 + 独立 Pr + Ywall_B=0.9、Yowner_B=0.1（缺陷组合）
1 壁面黏度相同的可变黏度 + 同一独立 Pr（控制）
2 常黏度 + 独立 Pr + 固定壁面组分等于 owner（控制）
3 常黏度 + 独立 Pr + zeroGradient 组分（控制）
4 旧常黏度 + 常 Pr，保留旧 owner 组分行为（控制）
5 可变黏度 + 常 Pr，保留原可变黏度固定壁面组分行为（控制）

所有状态满足 rhoK=rho*k，总能量包含 rhoK；流体和壁面静止。
Towner=700 K，Twall=500 K，muwall=1.8e-5 Pa s。
缺陷组合的 Prwall=0.88，正确 Cpwall=1550，原错用 Cp=1150 J/(kg K)。
