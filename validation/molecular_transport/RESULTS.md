# 原生验证记录：Sutherland / Wilke

基线：main `82ea1d90fc164fac27bc056e7b967feaa0406a5b`（PR25 已合并）。生产实现提交：`e0b6e271`。在原工作区下另建独立检出、独立构建和案例目录；未修改用户原工作区。本报告对应附带的初始输入和机器可读结果，不表示全仓库测试通过。

## 构建与硬件

WSL Ubuntu 22.04、OpenFOAM 10、CUDA 13.1.115、RTX 4060 Laptop 8GB，`sm_89`，64 位物理量/时间，完整应用 Ns=2。三个候选应用和三个基线应用都完成原生 CUDA 编译、主机链接和 GPU 执行。

完整应用验证使用额外 NVCC 参数 `--Ofast-compile=max -Xcompiler=-fno-tree-fre`，设备栈 65536 字节。基线 CHT 仅增加相同的可选栈设置和 NVCC 包装脚本入口，补丁附在本目录。不是 CPU 替代算子或仅 PTX 验证。独立 CUDA 物性/颗粒单测使用正常 `-O2`。

**常规优化的完整应用构建未完成**：基线和候选 gasUGKP 的编译进程均被系统终止；候选单独重试仍被终止（WSL 约 11 GiB 内存、4 GiB swap）。因此下列耗时只对应已验证的快速编译二进制，不能作为常规优化构建的生产性能结论。默认仓库编译选项未降低。

完整逐场差值和物性响应见 [native-results.json](native-results.json)。其中新增 CHT 多组分/数值壁层能力在 main 没有等价运行路径，未伪造对应基线；它们有独立的重启和 CUDA 算子验证。CHT 空颗粒场 `dMeanCell` 的既有重启辅助值不作为本次气体/固体一致性断言，报告仍保留其差值。

### 已有失败与精度界限

完整 `validation/tests/gas_wall` 在基线和候选均为 **562 passed、346 failed、24 errors**，失败/错误测试 ID 集合完全相同，没有新增 ID。存在旧编译标准、过期夹具/源码断言及数值断言问题；本次没有把它们掩盖为通过，也没有声称全仓库回归为绿色。相关新接口的颗粒测试夹具、移动后的共享壁层路径和依赖一致的串行参照已同步。

一些原始 CHMT 大耦合窗口用例产生已有的单次预测/校正波形失配警告。热接触用例的最大标度残差约 `6.53e5`，长窗口烧蚀约 `1.07e3`（Sutherland）/`1.61e3`（const/main）；这些用例只能证明执行、物性响应、const 和重启一致，不能作为耦合时间精度已收敛的证据。最终短窗口烧蚀用例在 main/const/Sutherland 均无波形失配警告；仍有机器精度量级的孔隙率截断诊断，详见告警摘要。未更改求解器的时间积分数学。

部分 CHT 用例有固体迭代预算警告，报告的能量残差约 `1.35e-8` 到 `1.83e-8 J`，略高于该合成案例约 `1.01e-8 J` 的限值，同时温度/表面残差已接近浮点舍入。没有通过放宽求解器检查隐藏它们。各案例告警见 [warning-summary.json](warning-summary.json)。

更小的非二进制整齐窗口还暴露了既有的尾部微步/下一步种子导致大量极小步的性能敏感性；探索运行已停止，未计入通过集合。本次未改变 PR23/25 的步长选择公式来换取计时改善。短窗口验证使用明确可表示的固定时间间隔。

## 架构与性能

物性表初始化上传一次，Wilke 的分子量配对常数预计算。没有新增每步 mu 的 CPU–GPU 交换、MPI 通信或全局同步；原有单元/面并行及壁层协作线程调度保留。壁节点物性在已有热力学缓存中复用，CHT 复用共用组分/壁层阶段，避免复制算子和在未准备壁层上运行 legacy 调优器。测试案例只提供输入，没有案例专用底层分支。

预热一轮、交替顺序五次运行，表中为进程墙钟秒数的中位数 `[最小, 最大]`。包含启动和正常输出，排除 blockMesh。部分运行期间有主机回归任务，且使用笔记本 GPU，存在明显离群值；所有原始测量保留在 [benchmark-results.json](benchmark-results.json)。

## 字典引用与 CHT 壁层输出修复验证

- gasUGKP/CHMT 重新编译并链接主机入口，CHT 重新完成原生 CUDA 编译和链接。完整应用仍使用前述快速编译模式。本轮只修改配置解析、输出连接及 CHT 的时间约定适配，没有新增每步物性搬运。
