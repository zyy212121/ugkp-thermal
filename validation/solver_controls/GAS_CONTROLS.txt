GAS / WALL / STEADY CONTROL INVENTORY (STATIC AUDIT; NOT A NUMERICAL PASS)
All sections use constant/scheme startup snapshot, merged by Scheme::module.
Precedence: precision-region > region > precision-module > module > typed default.
Both FP64 source and FP32 materialized source retain physical thermo bounds in
chemistryControls.thermo.minTemperature/maxTemperature. Numerical keys at that
old location are ignored. Physical species/model/transport properties stay put.

Gas model transport:
FoamGasModelInput constructs a dictionary, deletes any user model-file
solverControlOverrides block, injects scheme gasChemistry/gasThermo, serializes
at max_digits10, parses the same text on host, then passes modelText_ to
ugkwpGpuResidentStrictConfigureGasModelV1. Thus host and CUDA reparse identical
startup numerical payload, rather than independently rereading the model file.
GasModelIO applies only live keys; unused old maximumSteps, rejectedSteps,
initialStep etc are not advertised as effective controls.
