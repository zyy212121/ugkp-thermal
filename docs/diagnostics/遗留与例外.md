## 仍会终止的必要条件

- 拓扑／表示：非流形、实际塌陷或翻转、多重覆盖、拓扑改变；当前 Empty 零法向通量算子只实现双层轴对齐且精确配对表示。放宽成任意旋转／翘曲层需要实现另一算子。
- 缺失算子：单气体模式消费其他组分、未实现的湿膜表面反应及相应多孔相变组合。它们不是有限精度不达标。
- 存储／接口：数组越界、缺失必需输入、编译节点容量、不可表示字节数、真实分配失败、CUDA 或 I/O 失败。
- 实际物理：消费中的 NaN／Inf、非正温度／热容、零除数、真实库存耗尽等。有限误差 warning 不允许伪造物理结果。

这些边界不是新设的验收阈值；报告明确它们仍存在，未承诺“所有有限初值都能完成”。部分旧接口继续返回 bool／状态／字符串；已补本清单相关来源，不宣称所有辅助分支都有同样细的现场，更不虚构未知实体编号。
