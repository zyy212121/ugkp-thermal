# 遗留路径、保留机制及原因

本清单按首次发布后的全库复审及后续修复更新。这里列出的未处理项没有被默认为用户允许的例外；PR 保持草稿，不以编译成功或局部测试通过代替全部完成。

## 仍有候选选择、替代值或未统一的检查

| 位置／函数 | 现存行为 | 为什么未处理／验证边界 |
|---|---|---|
| `computeGasInternalFaceFluxKernel.cuh` 周期组分闭合；`computeSstFaceFluxKernel.cuh` 散度及 RK 组分闭合 | 为修正浮点舍入残差选择承载组分；原承载量不合适时重算和比较替换量 | 是有限次守恒代数修正，不重放物理时间步，但确有候选选择。直接删除会改变已保留的守恒／正性算法，尚未完成替代方案验证；不将它冒充 Riemann 例外 |
| `common/gasWall/WallGeometryBuilder.H` 的 cellSeed／凹面几何 | 两种投影边距以及最大三角形内部原点等替代构造 | 作用是建立几何支撑，不是失败缩短 dt；仍属于替代构造。复杂凹面表示及其有效性尚未逐项重构 |
| `applications/CHMT/mesh/Geometry.C` 轨迹认证 | 正向取向 epsilon 裕度、四面体扇与立体角容差可拒绝有限几何状态 | 本轮已将面积向量闭合残差改为 warning。剩余条件同时参与单一非翻转星形体积的数学表示，未证明删除后仍可正确计算扫掠体积 |
| `SweepWorkspace.H`、`SweepConstraints.H` 及 Geometry 显式容量控制 | 默认 256 MiB 工作区预算；可选自由度／模态／约束上限 | 预算不是实际内存不足，仍属未清理的策略门禁。预算还选择缓存／流式调和模态算法，未完成分配与计数联动改造。实际 size_t 溢出与分配失败须保留 error |
| `SharedGasDeviceStorage.cuh` 壁层池选槽 | 根据空闲显存比例／保留量选择池容量，可能在实际分配前拒绝 | 编译容量边界是真实限制；百分比与保留量是策略。二者尚未全部分离 |
| CHMT `Thermodynamics.H`、`Reaction.H`、`CpuMaterialDriver.C` | 热物性表定义域、配置孔隙率区间、部分 CFL 范围限制仍在 | 物性定义域／物理可用性与用户指定的更窄范围尚未逐项拆分；不能把这些条件全部称作除零或越界保护 |
| CHMT `InterfaceMath.H`、`CpuFilmDriver.C`、`EmptyExtrusion.H` | 部分单位法向／切向容差、双层 Empty 与轴向几何表示要求仍拒绝 | 部分是有限几何误差，部分是缺少支持的几何／物理算子；尚未逐条件统一分类。现有上层多经错误字符串转原生错误 |
| CHT `GpuResidentStrict.cu::applyGasGravityKernel` → `applyGasGravityCell<true>` | 共享 resident 推进中的气相重力仍把非有限密度／动量／能量替换成下限／零，未记录 fatal | 这是真实气相更新，不属于粒子算法排除；两相推进及 pureGasOnly 与固体热耦合的零粒子桥接均可进入。后续只读复审纠正了此前过宽的排除判断，本次冻结构建版本仍未改这条路径；已诊断的专用 gas-only 路径不覆盖它 |
| `OpenFoamWallFunctions.cuh` | Spalding／Jayatilleke 求根保留；部分失败／预算末尾返回零值 | 数学求根迭代保留。终端零值与调用方的物理解释尚未全部接入精确 producer 诊断，不能声称所有终端路径都已 warning/error |
| `common` 部分配置／物性辅助函数 | 非有限配置可能仍被当作未配置的 sentinel，例如直接导热系数选择 | 需区分既有 sentinel 与实际被消费的物理量；未通过新增一概拒绝的预检替代该辨析 |
| CHT `GpuSolidThermalProperties.C` 的 `outOfBounds=error` | 现有实现仍对表外值外推 | 本轮对实际消费的非法物性报 error，未新加表外范围门禁。配置名字与实现不一致仍须说明；有限正值外推保持原行为 |
| CHT 旧 `GpuResidentStrict.H` 部分输出流 | EpsGPrev／source-residual 写流未逐处检查最终写入和关闭结果 | 属于 I/O 诊断覆盖缺口，不是数值重试；主求解器及热耦合 write 失败已接 FatalIOError |
| 化学稠密线性系统失败与部分几何／液膜底层接口 | 仍有状态码、bool、错误字符串，部分缺少具体主元／矩阵项或实体数值 | 上层终止不等于每个底层位置都拥有完整现场；尚未逐分支补齐原始变量记录 |
| `tool/radiation/mieTables/make_alumina_mie_table.py` | 非有限相函数归一化替换为各向同性；非有限 Planck 权重被跳过 | 离线表生成工具，未在本轮转为 OpenFOAM/CUDA 运行时诊断。确实存在静默修复，已列出，不能计入“全库无降级” |

另有 `publishWallPrecision<double,float>` 保留直接窄化转换，可产生 Inf 并返回成功。实际 gasUGKP 壁层与 CHMT 当前固定使用 double，未找到生产 float 调用；这属于未统一的保留接口，不应宣称所有外部模板实例都安全。

部分独立辅助 API，如 `validateSingleGasInventory`、某些完整状态／normal-column 辅助函数，未找到当前生产入口调用，但仍保留检查定义。外部调用者是否可达未经证明，不能以未找到调用等同于已删除。

## 明确保留的算法和基础错误

- 原有 HLLC／Roe 等到 HLLE／Rusanov 的直接通量回退；有限正性 limiter、密度／能量下限。它们与先候选、再缩量、再试的循环分开。
- Newton、线性求解、SST seed 固定点、导热／界面／DO 固定点、标量求根和数学求积。有限未收敛结果在已迁移路径发 warning；不因保留数学迭代而免除非有限值检查。
- SDIRK、RK、Strang 数学阶段，以及预先选定的物理子步与 CFL 计算。成功子步推进实际时间；失败重放与步长减半已经在主要推进链删除。
- 必需数组容量、索引、指针／输入缺失、未实现的所选算子、实际非有限值／除零、CUDA API 和 I/O 失败。它们仍可终止计算；部分现场细度不足见上表。

## 粒子排除范围

用户明确要求粒子不覆盖。本轮不改穿面上限／失活、接触、冷壁薄层、粒子辐射、碰撞、CSR／粒子队列等原有行为。相应文件仍有有限修复、trap、局部求根和备用端点，不构成全库已统一的证据。

已单独追踪 `GpuColdWall1DGasOnly.cuh`：它操作粒子 pCold 数据并由粒子接触核调用，名称中的 GasOnly 指只与气相交换，不是纯气相求解器。共用 `GpuCouplingMath.H` 的实际数值调用也已追至粒子材料换热。

排除范围内的一个已复现问题是 `ParticleRadiationImplicitMath.H::conservativeBoundaryEnergyScale` 的零边界能量情形；原版与当前测试均失败，本轮未修改。共享 `MieTable` 的非法直径替代／非有限数据问题同样未改。排除是范围说明，不是正确性认证。

## 资源、工具及通信

- 资源替换失败时恢复旧设备指针或使所有者失效，避免悬空地址；文件短读、短写、EINTR、临时文件原子发布属于 I/O。它们不重放物理区间。
- `GpuToolB1` 的候选 block 大小、warmup 和计时重复是显式性能调参；`bartzSolidReplay` 是用户主动启动的离线回放。实际重复计算仍在，不能仅因不是失败重试就不报告。
- warning 默认开启；设备端在已有完成／回传点读取有界记录，新增次数与生命周期首次代表样本明确区分。不是每个事件无限缓存，也没有为每个事件增加同步。
- 原生 CHT CPU warning 遵循 OpenFOAM 的主 rank 输出策略。DO 线性 warning 每方向保存本次求解最后一次预算事件，不是完整逐迭代历史。MPI 运行时行为未实测。

## 已经补齐的旧清单项目

首次复审指出的 CHT 固体／界面／DO 有限迭代预算 warning、主入口异常转换、实际非法固体物性及主 write 错误，已在后续提交补齐。CHMT 最小二乘非有限清零、波形非有限值仅警告、无效 dt 替换、面积闭合残差硬拒绝、壁层 2／3 节点限制、物理子步数预算拒绝及有限零液膜预测界限，也已经分别修复。具体版本和测试见工作报告及发布后复审记录。
