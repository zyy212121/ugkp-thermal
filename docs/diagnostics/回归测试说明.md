## 已修复的真实问题

- 主机热物性调用方把失败当作可用状态，可能读取未初始化密度。
- 可选上下文为空时，热物性／壁层数学接口跳过上层失败状态而直接 abort。
- 梯度生产者静默返回，留下旧值；还误把有限的 1e300 当作非有限值。
- 已检测物理错误未同步到旧 cellStatus，及两种错误通道都缺失时的静默返回。
- 零秩化学对未用热容、比热／内能对未用熵参考量的拒绝。
- 纯诊断的密度求和、壁层积分和组分平衡溢出拦截有效物理结果。
- GCC 12 严格编译的初始化诊断、新增 OpenMP 测试缺少对应条件，以及源文件镜像清单遗漏。

各项保留修改前失败／修改后通过的独立复现。物理所需数据的错误控制同时保留，未用忽略错误、放宽所有阈值或重新引入重试使测试变绿。

## 非通过结果的其他原因

1. 测试桩／提取式测试尚未适配：缺少新 profile API 桩、warp intrinsic、诊断 helper/include，或仍调用已经删除的 rollback、terminal、shorten 等接口。此类测试尚不能验证相应运行行为；不能按通过处理。正确配置后的积分套件仍有 9 个未变的前端链接桩错误。
2. 有些断言要求 NaN／Inf／负温度继续发布，或检查已删除的线搜索计数。它们与新规则冲突。一个测试在首个非法输入断言失败后，后续有限子例没有执行，不能因此认定后续子例通过。
3. 有限初值并不保证完整 Newton 更新后仍物理有效。已捕获壁层负温度／负逆 omega 根、精确零主元、化学负反应因子进入 log，以及薄膜约 −43 K 的完整重构状态。旧回溯曾避免其中部分失败；当前停止是实际求解行为变化，需工程算例复核。
4. 排除的粒子路径中存在基线同样失败的接触／辐射／最终化测试，包括零边界能量的粒子辐射缩放。未为了整套测试全绿修改粒子算法。
5. 部分环境依赖未具备，如图形 Python 包；无 GPU 导致 GPU 执行跳过。编译主机模拟核不等于 GPU 并发或 race/sync 验证。

未批量删除失败测试，也未声称所有旧测试均无效。完整原始日志和独立复现保留在执行环境，PR 提交可复跑的新增测试与本摘要，未提交二进制或大体积运行结果。
