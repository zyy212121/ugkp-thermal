## 历史非通过结果

此前按多个目录运行的广泛批次跨越修复版本，属于发现问题的记录，不是本轮冻结验收。原始逐目录统计可在 Git 历史查看，不在此冒充当前统计。

必须分别归因：
1. 已删除 rollback／terminal／shorten 等 API 的提取测试及缺少诊断 helper 的桩，尚不能验证对应运行行为。
2. 要求 NaN／Inf／负温度静默恢复、或要求旧回溯计数的断言，与当前语义冲突；并非所有旧断言都因此失效。
3. 完整 Newton／重构可能真实地产生负温度、负反应量或奇异矩阵。先前观察到的壁层／化学／薄膜此类现象不能只标记为测试过时；需要实际工程算例判断影响。
4. 粒子接触／辐射／最终化属于排除范围；已知零边界能量问题在基线也存在，未据此认证粒子正确。
5. 环境／依赖和无 GPU 跳过项另计。主机模拟核不能验证 GPU 并发、race/sync。

本轮额外基线对照：六个 legacy SST 失败、两个协议字符串旧断言在 `ce55d189` 同样失败；这八项不归为本轮新增回归，也不计为通过。没有证据把其他历史失败全部归为基线或过时。
