# PR19 通用效率优化报告（2026-10-19）

本轮恢复了已定位的气相 SST 壁层执行成本回退。固定输入、固定 Capture、相同 7 次 Newton 的 CUDA 重放从当前 PR 的 380.743 ms 降至 194.799 ms，耗时减少 48.84%；相对旧 main 的 320.158 ms 减少 39.16%。优化版与当前 PR 的接受态、残差、热流及剖面逐字节一致。隔离正常算例第 100–224 步从 106 秒降至 52 秒，24 个最终输出文件逐字节一致。

这些是本次硬件和输入上的实测结论。本轮没有重新运行 64000 步，也没有把短算结果冒充原生产第 10000–25000 步的复测。原 14% 回退由已有诊断报告确认；本次同工作量重放已超过旧 main 性能，正常短算也显示收益。

## 改动及消除的执行成本

1. **壁层阶段隔离与容量专用分派。** Jacobian 节点组装、seed、Newton 更新和发布使用已有 CUDA leaf 约定，CPU 保持 inline。缩短跨阶段对象存活范围，避免整个求解过程共同决定寄存器分配。主机依据实际分配的容量选择 24/48/128 专用入口，避免一个入口囊括三种大型调用图；原动态入口保留用于兼容和无效容量诊断。
2. **并行 seed 的独立节点系数计算。** 物性、梯度和 SST 系数按节点分工；四个短递推、更新顺序和原有 FMA 调用点保留，因此不改变已认证的算术结果。非 simplex 输入保持串行 seed，以保留原 clipping warning 数量。没有改变任何迭代预算、容差或物理模型参数。
3. **复用接受态完整残差。** 候选通过原有可行性、完整残差和下降判据后，复制完全相同的已投影状态，保留已算出的 residual/norm，删除接受后第二遍完整物性/残差计算。此次 7 步 Newton 包含 1 次拒绝试探，完整残差调用由 16 次减至 9 次。真实初始/最终诊断仍启用；原残差中的组分 warning 在已投影 simplex 上不会被触发，其他属性/存储错误无法通过认证。多组分浮点探针验证该前提。
4. **每次壁层调用只准备一次不变表结构信息。** `LayerContext` 保存表结构完整性。完整存储路径不再按节点、Jacobian 列和扰动方向重复扫描元数据；该捕获输入重复 `layerTrialStorageAvailable` 调用从 1008 次降至 0。表不完整时保留按扰动温度选择区段的原检查，不缓存温度相关的物性或有效性结果。
5. **主机诊断目录静态复用。** 目录改为不可变静态对象；先合并 pending warnings / sticky fatal，再只复制快照实际使用的描述符。正常无诊断路径不再反复构造全目录及字符串。分配计数、跨 observe 的不同 warning、重复 finish 与 sticky fatal 均有回归覆盖。
6. **Courant 合并诊断读取。** mixture 模式在已同步、已读取并分发诊断的 validate 成功后直接返回标量，省掉没有物理计算间隔的第二次 observe。legacy 路径不变。
7. **limiter 复用同一次调用的拓扑检查。** 面索引/耦合/单元邻接只在第一次消费时检查；其他组分和第二次预测循环复用这个事实。没有删掉不同物理状态的有限性检查。primitive gradient 中无法证明等价的检查保留。

剖面仍在工作区覆盖前发布并同步。尝试过并行剖面发布，但独立收益不明显，未采用；五点缓存字段压缩同样没有稳定收益，未保留。没有把更快但会改变 FMA 结果的 seed 全递推并行方案纳入提交。

## 三版固定输入 GPU 重放

RTX 4060、24 SM、CUDA 13.1、`sm_89`、双精度、`-O3 --fmad=true`，真实 `cudaMalloc`，336 面，24 节点，Capture=true。每次 2 次预热 + 8 次记录，三轮交错版本顺序，每项 24 个样本；计时范围为求解和 Capture 内核，不含编译、分配和主机文件输出。完整样本与命令见 `evidence/final-replay/runs.json`。

| 输入 | 旧 main 中位数 | 当前 PR 中位数 | 优化后中位数 | 对当前 PR 耗时减少 | 对旧 main 耗时减少 |
|---|---:|---:|---:|---:|---:|
| 同质、每面相同 7 次 Newton | 320.158 ms | 380.743 ms | 194.799 ms | 48.84% | 39.16% |
| 真实异质面 | 374.414 ms | 371.606 ms | 187.200 ms | 49.62% | 50.00% |

同质三版均为 2352 次 Newton 总和、最大 7 次，最终残差 `1.5027988949520883e-12`，热流 `653.76765672560293`。三版同质接受态和剖面也直接比较；当前 PR 与优化版两类输入、三轮全部按原始字节比较，CSV、48384 个状态 double、72576 个剖面 double 全部相同。

异质面当前 PR 与优化版均为 2045 次 Newton 总和，分布 13 面×5、281 面×6、42 面×7。旧 main 为 2066 次，一面需要 27 次，其余相同。异质面性能包含原有数学改进带来的长尾差异，因此同质 7 次重放是单位工作量归因的主要依据。

旧 main 异质样本范围 324.876–375.228 ms，有波动；保留全部样本，没有剔除后择优。最终中位数、范围和数学工作量详见同目录 summary / mathematical-work JSON。

## 资源变化与分项实验

以下为实际 `gasUGKPCudaBackend` 的入口，不以微测入口代替生产入口。专用三容量的生产结果相同。

| 实际入口 | 旧 main | 当前 PR | 优化后 |
|---|---:|---:|---:|
| Capture=true 寄存器/线程 | 168 | 255 | 96 |
| Capture=true stack frame | 5424 B | 10864 B | 6320 B |
| Capture=false 寄存器/线程 | 168 | 255 | 96 |
| Capture=false stack frame | 5008 B | 10640 B | 6128 B |
| 寄存器等资源给出的 32 线程块驻留上限/SM | 12 | 8 | 20 |

CUDA occupancy API 的同结构微测直接得到 12/8/20，生产寄存器与块宽对应相同上限；这是理论上限，不是实测活跃占用率。未被正常容量选中的兼容动态入口仍是 255 寄存器。生产与微测 stack 不同：微测为 4832/10576/6160 B，原始文件均保留。

`cuobjdump LOCAL:0` 不表示没有 local-memory 流量；stack 和 spill 仍存在。容量 24 / Capture=true 的 ptxas 静态结果：入口 spill stores/loads 为 312/916 B，Jacobian leaf 为 1394/2844 B，Newton-update leaf 为 1044/884 B，team seed 为 68/124 B。它们是编译器报告的静态指标，不能相加当作运行时传输字节。完整调用上下文在 `wall-resource-context.json`。此前硬件计数权限不足的限制没有被规避，本轮没有捏造动态 spill 流量或实际 occupancy。

筛选实验（单批次、不同阶段；不能将百分比相乘）：

| 方案 | 同质重放中位数 | 结论 |
|---|---:|---|
| 原 PR | 376.35 ms | 筛选基准 |
| 只压缩五点缓存字段 | 376.76 ms | stack 下降但没有耗时收益，弃用 |
| 拆开四个阶段 | 330.89 ms | 约减少 12.1%，采用 |

接受态重复残差的单独收益沿用先前约 0.7–0.8% 的测量；本轮用调用计数和最终组合测量确认消除重复工作，不虚构每个小改动的独立百分比。容量专用分派证实生产寄存器从 255→96，未把资源下降百分比等同于独立速度收益。主机目录、Courant 与 limiter 的小项收益包含在组合短算中，没有分别声称可测的独立提速。
