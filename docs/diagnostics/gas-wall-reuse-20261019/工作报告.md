**逐项实现与取舍。**

1. 两条切向速度方程使用 `seedVelocityPair`，共同生成系数和执行一次 Thomas 分解，同时推进两个 RHS，再按原顺序分别回代。每轮速度分解 2→1；两条湍流标量递推及全部四个 RHS 保留。现有 CPU 捕获输入共 90 轮 seed，速度分解相应 180→90。保持 `dl+dr+mass+0`、RHS 递推和回代的算术顺序，不重排为会改变 FMA 的表达式。非有限或非正对角元仍在原位置返回失败。123 组不同节点、质量流、网格和 RHS 的双标量/共享分解结果逐字节一致，并检查无效矩阵状态。

2. `MixtureThermo.H` 新增 `speciesCpH`，`pointState` 每组分成功路径仅进入一次 `evaluateSpecies`，同时取 Cp/H。两组分为 4→2 次，任意组分数为 2N→N。H 失败时仍执行原 Cp 路径，保留 Cp 值与 first-fatal 语义。63,800 组温度、NASA/多项式分支、表尺寸、偏移、摩尔质量和非有限输入对照，数值及完整 DeviceContext 逐字节一致。

3. 完整残差中按区间计算一次通量，供相邻行读取；24 节点的 intervalFlux 45→23。仅用于不发布诊断、且表存储已经认证的 Newton 试探残差；节点源项仍使用原节点梯度。借用此阶段已失效的 `w.upper`，线程共同完成后再读取，没有增大 WallWorkspace。带实时诊断、或需要表存储错误归属检查的路径保留原行顺序、node 上下文及 warning 次数。初始/最终残差与发布不强行套用缓存。结果、拒绝路径、缺失 H 存储及工作区跨面复用均有回归检查。

4. seed 第一轮成功的普通节点计算后，把不变的 T/theta/rho/Cp/组分/H/法向系数存入闲置 `w.lower`。下一轮仍重算 u、sqrt(k)、z、omega、SST 梯度、涡黏度、反应与源项，并保留动态状态验证。第一轮边界通量保持原调用；原始组分需要裁剪时关闭本次 seed 的复用，避免减少 warning 次数。CPU 捕获输入中完整 pointState 次数由 2341→27（24 节点加原有初始化/首轮边界调用），不是缓存变化的湍流状态。缓存仅在一次 seed 内存活，下一面重新准备。

7. gasUGKP 的 convective/diffusion/SST 改为一次三分量 transform_reduce 和一次回传，保留三个独立最大值、负无穷初值、关闭 SST 时的零值与最终错误分发。若某个结果为 NaN，仅该异常分量回放原标量归约，保留具体 NaN payload 的选择；正常有限路径 3→1。CHMT 的独立适配器有不同诊断时序，继续使用原标量 fallback，未更改其内部算法。120 组真实 GPU 输入覆盖空数组、跨块尺寸、正负零、Infinity、NaN payload、SST 关闭及默认/非默认 stream，结果逐字节相同。65,536 元素、每轮 100 次查询的三轮主机可见耗时，中位数由 147.352→65.364 µs，减少 55.64%；这是归约查询微测量，不等同于完整 Courant 步骤收益。

8. Legacy 镜像、Riemann 镜像和波透射压力内核以 `nInternalFaces + threadIndex` 访问，只发射边界面；边界数为零时不发射。同步更新普通发射、CUDA Graph 调度节点、FSH/CHT 入口及 CHMT 视图元数据。内部面通量与梯度覆盖范围不变。72 组主机对照、12 组 GPU 规模对照和无边界 Graph capture/replay 检查通过。边界微基准提取真实内核正文，调度/邻接辅助函数使用确定性测试适配器；完整生产效果另由正常 A/B 检查。例如 1,048,576 总面、336 边界面，三个内核的合计线程数 3,145,728→1,152，三内核组平均 0.036874→0.031201 ms，减少约 15.38%。小网格受发射/计时噪声影响，有更慢的样本；所有测量完整公开，不宣称每种规模都有时间收益。线程数量的减少只依赖实际边界拓扑。

9. 已做设备端归一化网格预计算原型，保留设备 pow 与后续距离缩放的算术，结果逐字节一致。最终 24 样本中位数 177.898→177.881 ms，仅约 0.01%，落在噪声范围，未把额外配置/几何缓存生命周期代码加入生产路径。保留原型和原始测量，暂不采用。

10. 未删除 RK3 恢复入口。`invertCaloricEnergy` 的 Success 并不保证下一次恢复幂等：独立二次能量模型探针连续调用得到 1.5、1.4166666666666667、1.4142156862745099，均 Success，但 warning 次数分别为 1、2、3。SST 恢复还包含壁面 omega 投影。仅以守恒态未改变判断复用会改变数值和约束时序；需要明确“已达到可复用精度”和投影版本的契约后再优化。本轮保留现状。
