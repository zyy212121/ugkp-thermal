## 错误、误差与可选诊断

实际使用的负温度、非有限物理量、越界、除零、缺少所选算子或必需输入按 error 处理。有限守恒／精度残差按 warning 处理。有限质量分数越出 `[0,1]` 时按定义截断，不额外把存储组分任意归一化。既有混合气常数函数仍使用其原加权质量公式；这一数学定义与写回组分归一化不同。

未参与所请求计算的可选量不能拦截正常结果。后续复核据此修复了零秩化学对未用热容的检查、比热／内能对未用熵域的检查、原始密度求和的纯诊断溢出、壁层可选积分及组分平衡统计的溢出。实际物理通量仍逐项检查；诊断量本身可以保留 Inf／NaN 并发 warning，不伪造有限物理结果。

可选诊断上下文为空时，有返回状态的数学接口保留失败返回通道。void 算子优先保留详细首错，并补齐已有 cellStatus；两种通道均不存在时使用既有 fatal 后备。warning 不写入失败状态。这是错误通道后备，不是备用计算算法。

## 通信与输出

设备记录首个 fatal，在已有完成、同步或回传点由 CPU 调用 OpenFOAM 错误系统。记录包含步骤／时间、算子／源位置、实体、分量及数值等信息；部分旧辅助接口仍只有较粗的状态／字符串，未虚构缺失现场。

不为每个单元、面或 warning 新增 CPU/GPU 同步。已有完成点附带读取小型诊断；操作元数据由同一 stream 的小 kernel 更新，不新增 RPC。零长度下载不制造额外完成拷贝。设备计数和原子记录仍有执行成本，没有 GPU 性能数据支持“零开销”。

warning 默认开启，启动前设置 `UGKP_DIAGNOSTIC_WARNINGS=0`、`off` 或 `false` 关闭打印，仅影响输出。设备端按类别保留生命周期首次样本及计数，在既有回传点打印新增次数，并标识代表样本属于历史首次事件。它不是逐事件无限缓存。原生 CHT CPU warning 沿用 OF 主 rank 输出策略；MPI 运行时未实测。

## 保留的算法与排除范围

保留原有直接 Riemann 通量回退、有限正性 limiter、密度／能量下限、Newton／线性／求根／固定点数学迭代、RK／SDIRK／Strang 阶段及预选的物理时间推进。粒子穿面、失活、碰撞、接触和粒子辐射按要求不改。
