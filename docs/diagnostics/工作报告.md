## 行为原则

- CPU 使用 OpenFOAM 的 FatalError / Warning。设备端保留首个错误记录，在已有同步或数据回传位置交给 CPU；取消失败后重放计算的路径。
- 负温度、非有限值、越界、除零、缺少所选算子等实际错误终止相关计算。有限的守恒残差和精度残差输出 warning，保留已算结果。
- 有限质量分数越出 `[0,1]` 时按其定义截断并记录 warning。NaN 不通过截断变成正常值；不额外进行任意组分归一化。
- 保留原有直接 Riemann 回退、正性限制、密度与能量下限；保留 Newton、线性求解、求根、物理时间推进及 RK/Strang 阶段。粒子穿面与失活行为不在本轮改动范围。
- 不保留备用求解实现。旧实现只存在 Git 历史中。

## 设备通信与输出

诊断不会为每个单元或每条 warning 增加 CPU/GPU 同步。已有完成点附带读取少量诊断；请求头携带时间步和物理时间。设备元数据通过同一执行流中的小型 kernel 更新，不增加 RPC 或同步次数。前端与后台协议须一起重新构建。

warning 默认开启。启动前设置 `UGKP_DIAGNOSTIC_WARNINGS=0`、`off` 或 `false` 可关闭打印，仅影响输出。设备端按类别保留首次样本及累计次数，在已有回传点打印新增次数；它不是逐条无限缓存。首个 fatal 独立保留，后续通用状态不能覆盖其原因。

设备端状态读取使用原子 load；已检查 PTX，避免把正常热路径的读标记实现成全局 atomicAdd 读改写。此项仅有指令证据，没有 GPU 性能测量。

## 已知验证边界与遗留

已知遗留及其原因见 [遗留与例外.md](遗留与例外.md)，发布后继续对确切 PR 提交核验。不能将“未发现重试”解释为“全库所有检查已经统一”。目前需明确区分：

1. CHT 固体导热／区域耦合及辐射仍有真正的非线性、线性和求根迭代，属于允许的数学求解；部分诊断仍沿用旧异常／状态接口，尚未全部获得统一的细粒度现场记录。
2. 壁层几何预处理、Empty 网格表示、部分保留的独立辅助接口仍使用 bool / WallStatus / 错误字符串。上层可能转 FatalError，但不能据此声称每个底层分支都有温度、面号或变量记录。
3. 部分旧参数、枚举和 checkpoint 槽保留用于格式兼容；是否存在实际重试由调用路径决定，不按名字判断。
4. 粒子相关混合文件、离线回放工具、文件短写／EINTR 重试和资源分配失败后的指针恢复，分别属于排除范围、工具功能或资源生命周期，不是失败后的物理重算。
5. 历史测试中明确要求 NaN／负温度继续发布、残差拒绝或 terminal 备用实现的断言，与新要求冲突，应逐项列出。有效工况在删除恢复路径后出现的实际失败须单独报告，不能一概归为旧测试问题。
6. 当前无 GPU，未执行真实 CUDA 数值计算、race/sync sanitizer、长算或性能 A/B。编译通过不能替代这些验证。
