# CP1 FP32 热耦合耗时诊断

正式 CP1 在 0.295→0.300 s 跑了 63,060 个气粒微步。末次微步日志到第 60 次交换写出约 1,061 秒，含余下 484 个微步。此报告将正式运行的总耗时与冻结状态的分项测量分别列出。

诊断使用 CP1 的 FP32 CUDA 算子与实际网格、颗粒目录、SST 和材料参数。载入交换 59 的存档，保持该状态并直接触发一次约 5 ms 传热、约 10 ms 辐射的热事件。两者都从缺少 DOM warm start 的存档冷启动。定向诊断跳过整个气粒推进区间，颗粒分布、壁面累积热量和固体负载因此与正式交换 60 有差别。分项测得的是诊断事件。

| 热事件部分 | 定向实测 / s |
|---|---:|
| 完整事件含写出 | 1333.539 |
| DOM 辐射含颗粒材料反馈 | 1332.811 |
| 辐射结束至固体开始（含接口准备） | 0.005 |
| 固体求解 | 0.608 |
| 状态提交 | 0.005 |
| 提交后输出及收尾 | 0.108 |

强度变化、材料残差、发布场输运残差的目标依次为 1e−5、1e−5、1e−8。三者同时满足才正常结束。内层和外层对不同的状态计算残差。FP32 的舍入与抵消是需要核验的机制，单个容差低于机器 epsilon 不能证明方程无可表示的解。

另取同一冻结状态，在第 32 次源迭代后结束诊断，未发布物理候选。该前缀内 FGMRES 共 3.808 秒。预条件调用累计 3.080 秒（80.9%），独立角输运算子调用累计 0.300 秒（7.9%）。预条件内部的算子调用已包含在预条件时间内。其余时间包括 Arnoldi 正交化、真实残差复核、条件节点和计时开销。

正式存档文件修改时间只能描述写出先后。没有逐算子计时的正式宏观记录不提供分项秒数。此次耗时归因来自同版本、同控制的隔离事件。
