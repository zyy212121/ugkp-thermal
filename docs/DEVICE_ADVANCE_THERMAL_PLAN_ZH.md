# CP1 之后的热耦合与设备推进计划

本轮宏观验收已通过。后续 CHT 以 CP1 的 FP32 程序、入口配置、耦合方程、四项热流、颗粒统计及守恒台账为参照。CP2 从同一份交换 59 的状态推进到交换 60，以包含气粒演化的单次完整输出验收。CP1 的正式耗时为 1154.91 秒。比较时沿用相同硬件、时间区间、启动和落盘边界。[已接受的基线](../.build/architecture/cp1/case-current/baseline.json)

## 热事件的工作量

耦合辐射源循环依次求解角输运、更新颗粒热响应和光学性质，再复核已发布强度场的输运残差。CP1 同时约束强度变化、材料残差和发布场输运残差。前两项达标后，第三项仍可使下一轮重新运行完整 FGMRES、预条件和角向扫描。顶层热事件父图必须容纳这套迭代的完成状态与真实残差。[定向计时与残差轨迹](CP1_THERMAL_DIAGNOSIS_ZH.md)

CP1 冻结场实测中，DOM 用时 1332.81 秒，固体求解用时 0.61 秒。源迭代达到 10,000 轮，每轮 FGMRES 完整执行 200 步。前 32 轮的细分测量中，预条件占 FGMRES 时间的 80.9%。因此 P4 优先降低重复迭代次数，其次降低预条件调用成本，然后完成热事件父图。相函数更新与平衡在本次完整源循环中合计用时 141.43 秒。

### P4 的实施先后

1. **保留按求解器区分的终态。** DOM 报告强度变化、材料与发布场输运残差、目标、源迭代数、累计 Krylov 步数与退出原因；固体报告温度与表面更新、焓平衡、迭代数。GPU 上累计，在显式收集处读一次。定向计时器独立启用。
2. **先查残差停滞，再改有界迭代。** 对同一已发布强度、光性、壁面与颗粒反馈状态，逐项核对内层真残差与外层发布场缺陷的算子、归一化、松弛前后时刻及浮点累加误差。诊断时可用更高精度重评同一 FP32 解的残差，以区分可表示性、迭代停滞和真正的离散不平衡。保持正式 FP32 方程、物理更新与收敛目标。
3. **为无进展工作设置有证据的结束条件。** 优先验证状态不动点与有限精度循环，包括角强度、材料状态、辐射壁面、光性及真实输运缺陷。连续数次残差接近只能触发核验。若可证明后续迭代不会改善结果，在原预算内返回已算候选，保留未收敛标志、残差和 warning；真实收敛按现有判据报告。对于仍有进展的状态，继续有界求解。验证内外层结束条件联动，避免外层重复启动已停滞的内层求解。
4. **降低每个有效 Krylov 步的费用。** 根据前缀计时优先处理昂贵的预条件、粗网格修正和各方向三角扫描。先验证复用完全相同的算子结构、块因子和上风层计划，再考虑改进预条件或融合小 kernel。按拓扑、缓冲地址、系数及实际依赖分别判定复用条件。光性或边界材料更新后仍对最新算子执行真残差核验。Mie 相函数的可复用查询、插值与平衡依赖颗粒温度和粒径，固定网格本身不足以判定可复用。
5. **完成父图交接。** DOM 发布后，颗粒能量与矩刷新、固体求解按真实读写依赖分支；固体结束后发布壁温。容量服务保存进度，后继算子消费同一已接受结果。把已有固体图和角向并行分支直接接入。固体非线性保留原能量判据与端点报告，依据其自身实测成本排优先级。

内外层另设一个热事件共享的工作预算，按真实矩阵向量积与预条件调用累计，区分正常收敛、精度停滞、总预算耗尽与数值错误。在定向案例验证长时间仍有进展的路径后选取预算。遇到确有可消除的残差，可在剩余预算内用当前真残差形成修正，并检验写回 FP32 后的实测改善。耗尽预算时保留有限候选与原残差。该设计沿用既有 warning 发布契约。

### CP2 如何验收

在检查点内先用冻结场查验残差轨迹、有进展与停滞的两类路径、能量提交和缓存失效。再用唯一一次宏观运行检验整步效率与物理输出。对照同硬件 CP1 的总墙钟、热事件内分项、外层及累计内层次数；物理量使用总壁面热流、气体对流、辐射、颗粒接触热流、16 段轴向分布、颗粒质量与温度统计、辐射和传热各自账期的能量以及固体焓平衡。报告实际差值、残差和有限未收敛候选。阶段 P4、P5 之间只做编译与静态审查。

固定场诊断覆盖真实热求解器的一次调用，完整推进中的颗粒迁移和热通量历史由 CP2 的宏观运行覆盖。首轮优化不以放宽容差、删减散射或材料反馈、降低角阶或缩短物理区间取得效率提升。
