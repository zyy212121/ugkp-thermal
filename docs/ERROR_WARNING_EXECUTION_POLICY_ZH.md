# Error／warning 与有界求解契约

适用范围：本次清理支线及后续全部主线阶段；FP32、FP64 同时适用。用户于 2026-11-18 明确授权持续按此原则处理新发现的同类问题。

- schema、精度和模型身份用于解释字段布局、单位和顺序，不构成独立的计算准入政策。按实际字段读取；必要字段缺失、截断、不可解释的布局或不可用数值进入 error。不得修改旧文件标签以掩盖实际布局，不得把不同物种的数组按旧位置直接解释。
- 返回值表示结果能否使用；收敛标志与残差独立保存。有限、物理上可用的最终迭代结果即使未收敛，也发布并报 warning。NaN、缺失模型、无法执行的运算和无法使用的几何进入 error。
- 禁止因耗尽迭代预算或残差超限而重算完整候选、缩短已计算的物理区间或启动另一整套求解器。接受、历史消费、台账和时钟只提交一次。
- 可保留同一次求解内有明确总预算的数学措施：根区间保护、有效域内的 Newton 阻尼、避免单元翻转的几何搜索、预条件器构建失败时的对角替代。预算不得在“换方向／重建／恢复”时重新获得。算法回退及残差通过公共诊断系统报告。
- 性能判断需区分预条件器构建替代、内部数学迭代和完整物理候选重算。有限近似不得伪报为收敛；守恒残差与精度残差分别报告。
- 输出使用已有诊断汇聚和显式收集边界；不得为 warning 增加逐算子的主机同步。

## 本次支线的恢复点与验证限制

主线停在 CP1。CHT FP32 第一次宏观运行因用户要求停止而中断；已有首次热事件输出及日志保留，不能改记为数值失败。其余三个计算槽位未启动。原始宏观案例、输入冻结记录、已归档源码与二进制保持为恢复证据。

支线先完成读取、求解返回值、诊断和调用方发布链的清理，只进行编译和静态核查。支线完成后从 CP1 恢复，保留原中断记录并记录新源码与二进制；继续执行每检查点、每案例、每精度一次成功宏观计算的限制。第一个检查点缺乏可比较基线时只分析，不比较效率，不进行重复随机计算取平均。

## 实施决策与调用链审查

| 路径 | 实施与保留的边界 |
| --- | --- |
| CHT 颗粒重启 | 恢复历史布局分支；schema 9 的浮点冷态节点按真实宽度解码。对实际使用接触模型的颗粒逐节点检查所需焓和可用温度，缺失数据报 `InputData`，不修改历史文件标签。 |
| CHMT checkpoint | 去掉 schema 白名单、字段摘要及模型 identity 准入；配置版本用于选择解码布局，热历史宽度按实际记录长度解释。当前模型所需物种、凝聚相及元素预算按名称重排；缺失、歧义或无法解释的必需字段报 error。保留长度、校验和及实际数组尺寸检查。 |
| gas／transport／精度元数据 | 不再要求 identity 文件存在或哈希一致；当前选用模型仍验证实际系数和字段。精度变化只提供元数据 warning，数值转换溢出仍为实际数据错误。 |
| 化学 SDIRK／Newton | 物理区间只计算一次；两个 SDIRK 阶段保留。每阶段 Newton 与阻尼试探共享总预算，耗尽后发布已求出的可用新状态并保留未收敛报告，不缩物理时间步重来。 |
| 壁面 reference／coherent／legacy／equilibrium | 删除 reference 第二套中心 Jacobian 求解及 coherent 原地重建后重试。coherent 首次使用只复用物理初值构造，不再先完整求解 legacy 模型。有效域、残差下降搜索保留但共用求解总预算；有限新候选不因最终残差未达标而拒绝发布。coherent 的差分分支保护最多八次探测，不触发完整壁面重算。 |
| 混合换热 | 由公共热力学反解一次决定温度可用性；去掉外层重复收敛门禁，颗粒热量与气体反向交换照常提交，公共反解报告精度残差。 |
| CHMT 界面组分 | 唯一解情形预先选择专用方法；耗尽后发布有限结果，不串行启动整套多项式根隔离。确有多根的方法保留物理解选择；各根细化共用原总预算。 |
| 颗粒辐射 | 有效温度／能量候选直接发布，不再额外重算旧状态残差并以较差残差拒绝新结果。物性有效域内的更新限制保留；剩余残差由 DOM 外层有界迭代报告。 |
| CG／FGMRES／固体 | CG 最大次数为硬上限，最小次数不能突破它。真残差确认及 FGMRES 重启保留当前解与剩余全局预算；非有限残差立即终止该线性运算。固体有限未收敛候选保留，精度与守恒分别报告。 |
| AMG | 保留构建失败后的一次 Jacobi 替代；设备固体、设备材料、主机 FV 桥接以及 DOM 直接使用预条件器的入口均发布 `MethodFallback`，不重跑已经耗尽的 CG。DOM 在设备保留整个源迭代窗口内的替代记录，容量续跑不丢失它。 |
| 几何校正 | 保留固定目标下的阻尼、防翻转及几何认证；GPU 认证续跑沿用 `nextBacktrack`，不会重置搜索预算。CPU/GPU 调和求解的有限未收敛结果及最终扫掠残差本来就是 warning，继续保留。无可用几何仍报 error。 |

诊断新增 `InputData`、`RestartMetadata`、`MethodFallback`，继续使用公共记录格式、来源信息和 warning 开关。设备 warning 通过已有汇聚边界收集；主机已收集结果通过同一 OpenFOAM sink 发布，不增加 CUDA 同步。实际运算失败与未收敛已分别审查返回值、结果写入和调用方分支。

## 验证记录（支线代码与编译完成）

2026-11-18，CHMT、CHT、gasUGKP、gasUGKPSteady 的 FP32／FP64 共八个最终二进制全部编译、链接通过。最终源码摘要为 `0539da1680e311b8fe716e43be0284d3fbd49922c8a76d11534b498d2cdbdd69`；构建全程摘要未变，二进制与日志逐一核对。完整记录为 `.build/architecture/side-diagnostics/final-build.json`，各求解器日志为同目录 `compile-<solver>.log`。相关数值头文件、CHMT checkpoint 读取及 DOM CUDA 翻译单元也分别完成双实现编译；`git diff --check` 通过。

构建过程中出现过 GCC 11 内部崩溃，以及 FP32 独立 DOM 源码缺少新增诊断 kernel 定义的编译错误；后者已补齐。原日志按 `compile-*-pass*.log` 保留，早于最终修改的通过构建不作为最终证据。未修改优化或浮点选项，未将编译失败记为宏观计算错误。

原 CHT 内时刻的只读数据检查：26,317 个附着颗粒的 210,536 个一维冷态焓节点均有限、非零，范围为 1,063,498.5—3,072,606.5 J/kg；检查输出保存在 `archived-cold-history.json`。对用户中止前已有的两份 CHT 快照完成了统计解析，仍标为不完整运行，不能冒充通过结果或新基线。

本支线未运行计算测试。编译不能证明新的迭代结果精度或宏观守恒；这些仍需恢复后的正式 CP1 检查点检验，宏观案例未覆盖的化学与独立 gas／steady 路径只有编译及静态证据。主线恢复工具保留 `interrupted` 原状态，并单独记录用户恢复授权、修订源码与二进制，成功运行不能借此重复占用槽位。
