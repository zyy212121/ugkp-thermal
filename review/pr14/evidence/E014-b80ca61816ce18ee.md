## Production changes and direct consumers

`field-consumer-cost.json` gives the per-owner field, consumer, status, precision and local cost matrix. The relevant changes are:

1. **Geometry:** `makeGasFaceFrame` publishes all eight frame values after its original normalization/divisions, even when the numerical certificate fails. `shiftGasStateToFaceFrame` publishes primitive and all five conserved values; `restoreGasFluxFromFaceFrame` publishes all five fluxes plus signal/scheme/fallback metadata. The stationary signed-zero identity branch is retained. `gasGeometryFaceFrame` and `gasGeometryCellVolumes` expose evaluated flags and retain false certificates; actual missing pointers still mean no evaluated result. Declared face/cell counts no longer reject the supplied actual backing in these terminal helpers.
2. **Boundary primitive:** moving mesh speed is actually divided, not silently replaced by its seed. EOS density and selected velocity publish on the terminal route despite numeric certificates. Previously unsupported mixture total-condition selection invokes the existing total-condition helper using the actual mixture gas constant and the owner-temperature frozen caloric ratio `(cv+R)/cv`; it still records UnsupportedConfiguration. This is not a new general variable-Cp inlet solver. PWave/scheduled markers retain their status while the selected existing boundary arithmetic proceeds. Strict behavior remains its original owner-return/selection. Gradient consumers receive this actual primitive via `riemannFacePrimitiveForGradient`; the gradient/limiter loops themselves were not changed.
3. **MUSCL:** the full attempt loop `0..64`, alpha halving, attempt-63 alpha reset, first-order route and every previous complete-candidate fallback are retained. Only terminal attempt 64 with no previous complete candidate gets the actual final EOS/primitive/Y publication. Strict failed output remains atomic. No earlier eligibility/complete test was loosened.
4. **Riemann face:** status/unsupported selectors no longer prevent terminal tail work. The existing selector fallback is actually computed. Moving left and right shifts, selected five-component Riemann flux, species advection, restoration, subgrid heat and corrected diffusion finish before the final five bulk writes on covered terminal cases. The added nonfinite-coefficient traction/work entry has an independently identified original-success regression and is pending correction. Numeric failure is recorded and returned as its old local certificate. Actual unavailable geometry/thermo remains incomplete. `normalise` still defaults to strict standalone behavior; the face wrapper explicitly selects terminal continuation. Existing nested scheme fallbacks, mass carrier repair and successful arithmetic order are preserved.
5. **Calorics:** terminal face callers use B1 complete `evaluateMixtureEnergy`/`evaluateSpecies` with availability flags rather than treating a scalar NaN or non-success status as proof that no backing could be evaluated. Boundary energy/capacity share one species pass. Reconstructed partial-density energy and mass-fraction heat capacity retain separate traversals/weights to preserve expressions and rounding. Strict callers retain the original scalar caloric selection.
6. **Diffusion:** all raw/corrected species values, dependent-carrier closure and the full formation-inclusive enthalpy sum are computed/published on the terminal route. Null molecular diffusivity retains its legitimate zero molecular contribution. Strict failed output remains atomic. Missing property backing is still unavailable.
7. **Subgrid:** all four outputs (mu, k, direct heat, active flag) finish through the actual Spalding/Jayatilleke/EOS closure despite numeric certificates. Laminar and non-wall-law SST complete-zero branches remain legitimate original outputs. Thermal strict early exits remain, while terminal conductivity/heat formulas execute. Selected BVP-wall exchange is unchanged and awaits B5.
8. **Periodic and positivity:** terminal nonfinite periodic values do not leave only one channel published; the two original write orders and original carrier-repair eligibility/order remain. Covered mixture positivity completes every factor after actual inventory/species arithmetic while recording numeric errors; legacy no-species nonfinite-volume trapping remains open. Original bulk `finiteOr`, donor/shared factor, clamps, skips, dt<=0 all-ones branch, application kernel and wall-energy ledger remain.

The original kernel's initial zeros were not relabeled as computation. Helper evaluated flags distinguish a completed numeric failure from truly unavailable data. Other direct consumers outside B2 (notably B3 stability/geometry and B7 unified status handling) must use this distinction. A false helper bool alone is still a certificate, not necessarily absent output.
