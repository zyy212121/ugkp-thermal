## Confirmed failure and native repair

V1 compared the prepared layer velocity with a newly completed primitive using `!(mag(delta)>tolerance)`. For a changed terminal input, NaN made this unordered comparison select reuse. A new trace then accompanied old finite traction/heat. The independent probe confirmed changed NaN/Inf wall velocity, NaN normal and NaN normal speed, with normal and finite-change controls passing.

V2 keeps the original finite-vector comparison literally unchanged. When either vector has a nonfinite component, each component must instead be equal or both NaN to reuse. Mismatches select the existing actual fresh closure. This is a reuse decision, never an admission gate or numerical refusal. A new closure lacking its genuinely required workspace still fails without publishing stale output. Matching prepared-only inputs still need no new workspace.

### Necessary same-terminal primitive-tail finding

While extending the repair to actual positive/negative infinity components, a focused test found a second issue in the same reuse chain: with unchanged `normalSpeed=+Inf`, the layer correctly reused with zero solves, but the prepared primitive had one wall-velocity projection while fresh `evaluateInterfaceGasClosure` first projects wall velocity and then calls `makeInterfacePrimitive`. The fresh terminal result therefore had different Inf/NaN packet momentum classification. This was real missing arithmetic, not a reason to normalize classifications or to demand another layer solve.

For matched nonfinite vectors only, v2 now performs the same existing fresh projection sequence for `closure.trace.velocity`, using the already computed real density and mass. The actual equations are:

1. wall velocity = supplied velocity - normal * dot(supplied velocity, normal) + normal * normalSpeed;
2. primitive velocity = wall velocity - normal * dot(wall velocity, normal) + normal * (normalSpeed + mass / rho).

No values are clamped/substituted. No thermodynamic species loop or BVP is repeated. The ordinary finite path's arithmetic, tolerance and output remain unchanged. The parent's explicit direction permitted this necessary same-reuse terminal-tail completion; it does not broaden the repair into B6/B7.
