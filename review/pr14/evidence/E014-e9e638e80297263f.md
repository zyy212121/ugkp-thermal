## Measured cost scope

`measured-costs.json` compares one cell, two faces, Ns2 chemistry, no wall/SST. Base source is fixed 5f1a39a. It is a host CUDA allocation/copy/sync instrument, not a GPU timing claim. Base record is reused when only final host CudaFault layout changes.

- Resident CUDA allocations 142 -> 141; bytes 4024 -> 4004 (20-byte ChemistryStatus removed).
- Trial clear calls 4 -> 3; bytes 104 -> 84.
- One checkStatus: D2H bytes 32 -> 12; synchronization calls 4 -> 1; zero allocations/frees on either check.
- Wall numeric-only status removal saves its count-sized int D2H and one sync per check when enabled.
- Full bulk copy saving per removed validate: 8*Ncell*(5+Ns+2 if SST) bytes, five bulk + optional species + optional two SST copies. The original successful commit still gets one full download.
- New host facts do not change SharedGasDeviceView. Final owner sizeof is recorded by the final cost receipt; do not reuse the earlier pre-runtime-fact sizeof as final.
- No claim of zero GPU reduction temporary-storage overhead; the actual widened reduction was compiled with real Thrust/nvcc, GPU runtime unavailable.
