# Independent B1 review

Decision: **CHANGES REQUESTED**. Two P1 findings block accepting the frozen B1 patch. Review applies to base `82f9c016704c9822b16b87cdeeb11f5bbd44d06f` plus patch SHA256 `3ddee9345067595cbc4b82858a3ff8ed5ad4a91a4fb0a2fc958870a1f30f4e23`, not subsequent edits.

## Findings

### B1-R1 — P1: preserve the already-successful outer material fallback

Location: `common/gasTransport/MixtureThermo.H:331–339`, especially the unconditional non-refinement `completeCaloricEvaluation` at line 337. Direct consumer: `applications/CHMT/materials/Thermodynamics.H:85–94` (`invertMaterialEnergy<true>`); production caller `recoverSolid<true>` around lines 171–178.

The new nonfinite-target branch executes an arbitrary evaluator at the existing finite seed before returning `NonFiniteInput`. The existing `TerminalMaterialEnergyEvaluator` records that evaluation as available. Previously common inversion returned without an evaluation, so `invertMaterialEnergy<true>` evaluated the lower endpoint itself and successfully published it. The patch therefore changes a successful outer fallback despite retaining the inner error status.

Independent evidence:

- The existing `applications/CHMT/tests/test_terminal_caloric.py::test_terminal_material_caloric_outputs` fails on the frozen patch at `assert(T==100)` (1 failed). The identical generated C++ probe, compiled against an actual `git archive` of the base's common and CHMT source, passes with exit 0.
- A smaller independent probe calls the real production functions. Base: `recoverSolid<true>` succeeds with T=100. B1: it succeeds with T=0. Its condensed inventory is one unit, cp0=100, cp1=0, e0=7, Tmin=100, Tmax=3000, no pore gas, and NaN energy.
- The same probe directly calls `invertMaterialEnergy<true>` with an ordinary linear caloric evaluator, NaN target, lower=100, upper=3000, initial T=99. Base succeeds with T=100; B1 succeeds with T=99.

This is an introduced regression, not the unrelated capability failure. Preserve the original generic callback/fallback sequence when the enclosing producer already succeeds. Terminal completion must be selected at the actual terminal owner or otherwise avoid preempting that existing successful outer fallback. Do not fix this by updating the expected endpoint or adding a numerical rejection.

Receipts: `independent/terminal-test.log`, `independent/terminal-base.log`, `independent/review-probe.cpp`, `independent/review-probe.log`.

### B1-R2 — P1: declared metadata still prevents the requested species completion

Locations: `common/gasTransport/MixtureThermo.H:37–45`, early return at line 62, and NASA7 selected-segment return at line 82. This is unfinished required scope rather than a newly introduced refusal.

B1's brief explicitly includes the label/count/offset certificate refusals mixed into `validMetadata`. The shared plan and parent clarification distinguish these from a genuinely null consumed pointer or a selected model with no formula. The frozen patch leaves these refusals untouched and its report incorrectly groups them with unavailable backing.

The independent probe uses sufficient real allocation in every case; it executes no OOB access:

1. LinearCp has a real three-element coefficient array but `coefficientCount=1`.
2. A view declares Ns=1 but points to two allocated species and six allocated coefficients; evaluation requests the allocated species at index 1.
3. The coefficient pointer points to the fourth element of an allocated six-element array, with offset=-3; the selected three coefficients lie inside that array.
4. NASA7 has all 14 coefficients allocated, `coefficientCount=7`, and T=2000 selects the actually allocated high segment.

For all four, frozen B1 returns `InvalidModel` and retains all five distinct old outputs (-11, -12, -13, -14, -15). This means the requested producer tail has not run. Merely retaining the status until B7 does not excuse leaving the bundle unpublished.

Separate pointer/model absence from supplied metadata certificates in the terminal route. Preserve original successful property-availability NaN/entropy routes and strict retry choices; do not invent coefficients, add new gates, or intentionally test invalid memory accesses.

Receipts: `independent/review-probe.cpp`, `independent/review-probe.log`. All four reproduce on the base too, as expected for an omitted completion obligation.
