# Independent particle-terminal review

## Verdict

No blocking production-source defect identified in this scoped patch. Source review supports the intended terminal publication changes while retaining old successful-path arithmetic. The recorded native CUDA compile evidence is real but incomplete; one shared cold dependency has changed since compilation. This is **not** a complete owner build/device-link or GPU correctness approval. No test, compiler, runtime fixture, OOB case, longrun, index, commit, push, README or production source change was performed by this reviewer.

## Evidence integrity and exact extent

- All 24 live owned paths and all 24 frozen source copies match source-manifest.json (23 production + 1 existing test). All 23 baseline production copies match their recorded hashes. The baseline test copy is absent; its recorded baseline hash is verified directly against git 55b7192.
- All 66 artifact-manifest entries match their recorded hashes, including objects, commands and empty compiler logs. Ten recorded nvcc return codes are zero, using C++17, relaxed constexpr, sm80. Two collision variants use -dc; no final device link is recorded. Remaining variants use -c.
- Eight small translation units instantiate actual included native helpers/operators. Collision supports thermal/nonthermal branches; transport supports CHT/FSH adapter branches. Pressure wrappers call declared kernels/backends, so pressure device implementation/link correctness is not established. State declarations, RNG/helper adapters and unrelated cold reset/init adapters are fixture scaffolding, not full native owner layouts. No numerical behavior was inferred from executing that scaffolding.
- The 41-entry closure includes eight fixture .cu inputs and repository quoted-include dependencies. It is a literal include crawl, not a compiler depfile covering CUDA/system/compiler-generated internals. No repository generated-header dependency appears in these eight units. It does not prove full application include/dependency closure.
- Forty current closure entries still match. GpuColdWallSolidification.H changed through the separately owned CW1 repair. Prior objects remain valid receipts for their recorded input, not current combined-source proof.

## Source checks

Sampling preserves two normalPairDevice calls (four draws), stores through existing finiteOr(sample,target), diameter clamps, contact state handling, RNG publication, thermal raw signed mass and nonthermal clampMin(finiteOr(mass,0),0). The four weighted-moment atomics retain order. Correction and drag remove final classification traps without changing successful velocity, exponential/small-series, pressure-gradient finiteOr, singleton or low-energy formulas.

Material/contact/capillary helpers now return their evaluated material, impact, damage, physical area/mass and heat fields instead of false-plus-zero substitute structs. Diagnostic validity still accompanies evaluated fields; native inactive/no-heat branches remain intentional identities. Transport publishes computed contact duration/maximum area/peak fraction and continues old state transitions. Finite-contact relaxation computes the actual candidate, commits temperature plus enthalpy residual, and performs the wall-energy atomic before existing age/rebound/deposit transitions. The no-carry fallback publishes actual lumped temperature/energy; its zero residual is representation-specific, not a fabricated failed heat result.

Thermal carry's TerminalPublication parameter defaults false. Ordinary heat and affine-radiation callers retain strict finite refusal and old successful arithmetic. Only finite-wall consumer calls use <true,true>. Accepted-heat limits, temperature clamps, and double residual cancellation/order remain. Nonzero terminal arithmetic reaches real state stores and actual heat, with finite diagnostic status rather than unconditional success. Existing zero-conductance/equal-temperature/proposed-zero identities still return zero exchange; those no-op paths must not be interpreted as a fresh validation of every unused input.

The spread-search function is byte-identical to the frozen pre-batch HEAD 55b7192 version. Compared with original successful reference d6110, prior work had already changed exception admissions and failure returns (-1 versus NaN/upper). This batch preserves its bounded expansion/bisection order and successful formulas; do not claim that its entire exceptional behavior is byte-identical to d6110. The public impact function continues from its actual search result into remaining fields.

Wall-interface integration retains age-zero and area-zero identities, stable log1p-minus-x polynomial/log split, and transient resistance formulas. Nontransient zero resistance now evaluates the native IEEE quotient. Finite-contact integration retains inactive area skips and accumulation order. Lumped heat preserves its 48-update bisection; carry consumer preserves its existing 64-bound loop/update and termination expression. Removed numeric refusals do not constitute proof of a finite solution for exceptional input.

Pressure and packing enabled dt==0 return before grid calculation or launch, giving the requested identity. Negative/NaN/Inf dt has no new host numerical refusal and proceeds into unchanged launch/backend arithmetic; native field behavior remains GPU acceptance. Actual launch/cooperative errors and unavailable cooperative-grid failure remain. Automatic CSR retains modulo-zero and block-zero errors, and removing nCells refusal allows noninspection no-cell scheduling advancement. Inspection still exposes native launch behavior.

Reduction writers accept backed descriptor addresses beyond capacity labels, plus empty/reversed descriptor ranges. Materialization no longer rejects local count mismatch; it does not repair incorrect metadata or prove subsequent consumers use a semantically correct count. Payload gathers preserve negative-address rejection, actual primary-field copying and cell checks while admitting backed source indices beyond a lower capacity label. Updated fixture source backs index 1 with two source elements; no old one-element/index-one OOB fixture was executed. Existing selected-count clamps and genuine consumed address/CUDA failures remain. No new count/version/numeric admission gate is proposed.

The patch introduces no float physical storage, allocation, memcpy, synchronization, scan or launch. GpuReal/GpuTime/wall energy remain double in reviewed dependencies, with double enthalpy residual. CHT cold profile 8/64 storage policy and cold nonlinear retry algorithms are separate CW1 ownership; no duplicate review or changes were made. FSH physical math remains double. Performance remains unmeasured.
