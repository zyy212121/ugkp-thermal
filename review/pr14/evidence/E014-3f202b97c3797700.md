## Native changes and preservation

- Particle radiation transaction: removed numerical-only full-cell/boundary snapshot and completed-result walks, retaining required array/patch backing checks. Original canonical clamp loop, activity skips, operation order, and real exception propagation remain. Computed root/energy/face values reach real result fields.
- Root and phase helpers: removed terminal numerical throws; kept evaluated endpoints, brackets, bisection progression, maximum-iteration behavior, native probability/scaling formulas, and measured candidate selection. No catch substitutes uninitialized/default results.
- Boundary energy: preserved original successful near-zero identity and zero/zero identity; other cases use the real division, including IEEE overflow/zero-divisor results. Faces are physically scaled once. The second call remains diagnostic-only with the original successful arithmetic and accepted-plus-applied fallback, never a second face scaling.
- DO: preserved existing clamps and directional/source/linear iteration order. Removed numerical input/output certificates and the all-cell diagonal certificate walk. A nonfinite initial residual or NaN target now causes one real RHS/diagonal sweep rather than publishing cached intensity; originally successful finite-residual no-op, including finite-input target overflow to infinity, stays unchanged. Native last computed candidates are retained.
- Solid: finite individual interface energies may overflow a diagnostic total without withholding finite local fields. Removed numerical surface/gradient/conductance/effusivity/result/publication checks, retaining actual IO, mesh/array, operator, and integer-modulo requirements. Aitken's actual search/fallback decisions remain.
- Solid properties: native interpolation/product/enthalpy/secant results continue. Existing successful interval arithmetic, integration order, and clamp behavior remain. Unordered queries select a backed pair. NaN knots receive a strict-weak sort order so removing their admission check does not violate sorting requirements.
- Mapper: original finite nearest search and tie order remain. Only its formerly failing no-candidate tail computes shared-scale distance comparisons and picks an actual evaluated candidate. Huge finite distances retain a meaningful nearest comparison. Empty target storage remains an error; no -1 index is published. If every comparison remains unordered, the first evaluated backed face is retained.
- Mie input: successful stream conversions remain unchanged. Failed scalar conversions get an actual strtod IEEE conversion; malformed/missing tokens still fail. PHI retains original direct extraction and retries only failed conversions. The bracket search keeps its old progression and evaluates an existing endpoint pair on unordered comparisons. Existing logarithmic fallback/clamp behavior is unchanged.
- State: only active pending-ledger scalar-finiteness clauses and elapsed-deltaT veto were removed. Face-index backing and actual missing files/entries remain required. Unused legacy restart-field validation/checksum functions remain untouched and are not claimed as removed runtime work.
- Removed diagnostic-only hot-path std::string temporaries by making unused literal context/location parameters const char*. No arithmetic reorder.
