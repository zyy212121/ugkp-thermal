## Implementation

### Completion is classified where output is produced

The existing cell/face channel now records true unavailability as sticky `InvalidStorage`. Local evaluated facts from primitive/geometry/reconstruction/diffusion/chemical/wall publication distinguish this from completed numerical diagnosis. Subsequent numeric writes cannot erase actual missing input. Public CHMT/native validation consumes this distinction; native strict validation still sees original diagnostic codes and retains its accepted retry path. No global whitelist of ambiguous ChemistryStatus values substitutes for producer completion.

Native final nonretry numerical diagnoses may reach the existing real public continuation over the actual remaining interval. Original successful retries are unchanged. CUDA status-copy errors, including the failed-wall detail copies, explicitly clear continuation eligibility. This was caught during B7 fault review and repaired with a five-copy-position red/green control. Actual rollback copy failure still poisons native storage and retains B6 unique failed-free ownership/release propagation.

CHMT no longer allocates, resets or downloads its typed chemistry status: no real consumer remains after producer classification. Native retains this channel and its snapshots for strict inner retries. Cell/face status remains for actual missing inputs. CHMT removes numeric-only wall status reads from global checks, two redundant status download synchronizations after the existing device synchronization, and repeated full-state downloads from validate. The actual state is downloaded once before commit. All actual copy failures remain checked.

The actual common trial executes two chemical half calls, capturing each audit with its real old/new volume. Begin clears the two host scratch vectors without discarding capacity. The wall stage callback no longer refuses mismatched prepared time/readiness or consumes stale pressure/profile. It invokes the existing current-stage producer and refreshes selected common face fluxes when preparation is stale. The ordinary prepared stage adds no closure; an instrumented actual producer call verifies that, and verifies exactly one new preparation for the changed stage. LowRe packet failure can execute its existing terminal closure rather than rejecting a completed bulk state.
