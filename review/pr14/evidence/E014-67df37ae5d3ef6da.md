## Native repairs

### R1: rejected wall candidate ownership

Move the existing `BoundaryLayerAllocation` declaration to the already-used `SharedGasTrialFields.H`; define it once. An embedded `gasTrial.rejectedWall` holds only the fixed owner metadata. No CUDA array, host heap allocation, numerical cache, extra physical snapshot or extra publication call is added.

Every candidate-discard tail now calls `discardBoundaryLayerCandidate`: staging allocation/table-copy failure, later input/exchange-copy failure, failed snapshot release, and failed old-wall release. It attempts every actual release. If any free fails, the remaining pointers move once to `rejectedWall`, the local candidate clears, and the existing resident actual-error poison prevents another configuration from overwriting that owner. The old accepted wall owner remains separate where its release also failed. The actual DeviceState overload of `releaseBoundaryLayerStorage` releases both the resident and rejected owner, continuing to attempt both even if one returns an error. A repeated teardown failure leaves the same pointer owned for the next attempt. Production `releaseState` reaches this overload.

### R2: fallible snapshot release and related replacement tails

`releaseSnapshot` and `releaseSharedGasTrialStorage` return the aggregate actual CUDA failure while attempting both snapshot levels/all channels. Partial release invalidates snapshot validity and reuse-size metadata, but never discards a failed pointer. Wall replacement and zero-wall disable return the release failure before publishing another wall; a prepared candidate is discarded through R1's owner-safe tail. Snapshot-only release failure leaves the unchanged physical wall usable/retryable, so it does not add an unnecessary poison condition.

`ensureSnapshot` now returns immediately on a failed old snapshot release, before replacement allocation can overwrite its pointer. Its already-failed allocation cleanup still returns its original error and leaves any failed cleanup pointer in the live snapshot. A changed wall-record size similarly returns the actual free error before allocation or D2D copy; validity is cleared and the old byte extent remains with its owner until successful release.

The same release primitive also exposed an adjacent `releaseGasBudget` tail: its three owners are now aggregated and retained when free fails, rather than overwritten by an empty view. The actual configure-budget failure cleanup marks the resident poisoned when the free fails, preventing later setup from overwriting those retained pointers. The existing host ledger close/delete still occurs; physical-budget model/file sequencing is otherwise unchanged. Production terminal destruction remains its existing best-effort void lifecycle and records actual CUDA errors through the existing last-error helper; no new public operation was introduced.

- actual `Advance` / `AdvanceGasOnly` contains no `syncDeviceState` call. No per-step full-state publication was introduced. The unrelated common thermal occupancy synchronizer is not included in this native TU.
