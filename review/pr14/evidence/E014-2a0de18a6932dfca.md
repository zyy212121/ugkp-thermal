## Result and scope

The chemistry producers now distinguish actual output completion from a numerical diagnostic. Scalar rate/progress arrays, all AD derivatives, basis normalization/left-inverse solves, reduced RHS/Jacobian, masses/temperature, both SDIRK stages, the actual remaining interval, and density/budget/audit publication perform their original arithmetic instead of leaving sentinels, default zero derivatives, old states, or short-time substitutes. Diagnostic statuses remain visible. Actual missing consumed inputs still return unavailable output.

The original public strict refinement path runs first. Its original 8-epsilon pivot selection, EOS inversion, Newton/line-search criteria, iteration counts, damping, SDIRK coefficients, full/half/second-half order, error divisor, adaptive factors, subnormal rounding, and retry-owner API remain in place. Only a former terminal failure enters completion. No successful equation was reassociated, no tolerances/default steps were weakened, and no new numerical/metadata/identity/count refusal was added.

A numerical failure writes the real IEEE q/production/derivatives rather than a placeholder. - Gibbs channels: a terminal Gibbs consumer can request actual h and entropy through a trailing, default-false CompleteEntropy flag on the existing caloric bundle. - ReactorContext: preparation and evaluation publish complete leftInverse, scalar RHS, and the rank-by-rank Jacobian with independent availability facts. B1's actually evaluated temperature can be used alongside its retained diagnostic. Scalar availability is not inferred from AD status, and AD availability is not inferred from scalar status.
- Stages/time: completed stage output is an explicit fact, independent of status. Each required first/second stage is really evaluated. Terminal full, half, and second-half calculations use the current accepted prefix and actual remaining interval. A rounded-away proposed duration is replaced by that remaining duration before any physical stage work, never by a fabricated clock increment, nextafter, or endpoint label. NaN/infinite/negative interval inputs execute one complete set of their actual interval expressions; their audit retains that supplied interval and their diagnostic. This is arithmetic completion, not a claim that a nonfinite duration is a finite physical solution.
- Terminal line-search state diagnostics are forwarded as well as scalar/AD diagnostics. A direct stage test demonstrates a caloric overflow with still-finite scalar rate; its real mass/RHS are published without losing the caloric diagnostic. It fails against the retained pre-repair headers and passes against the final source.
- Adapter: pre-reactor numeric checks and density-conversion overflow no longer abandon actual computation/publication. Volume-to-mass, kinetic/internal-U, bounded dependent-coordinate correction, rounded audit, budget delta, and density writes retain their order. Zero time retains density bits. Conserved rho/rhoU/rhoE are not written. Optional evaluated output is true only after publication (or a legitimate legacy/frozen no-op). A host/device volume-pointer entry checks genuinely missing stage volume after those skips; the CUDA kernel uses it instead of substituting zero for a null pointer.
