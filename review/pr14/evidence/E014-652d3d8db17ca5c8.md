## Native changes and source preservation review

- Sampling reaches its existing `finiteOr(sample,target)` outputs, then advances the original RNG and publishes weighted moments. Nonthermal `clampMin(finiteOr(pm,0),0)` remains; thermal signed mass remains raw. No Gaussian draw, draw order, reduction/atomic order, diameter clamp, contact reset, or original inactive/singleton branch was changed. Correction and drag publish the native velocity expressions instead of trapping on their numerical classification. Exponential/small-series drag and pressure-gradient finiteOr remain unchanged.
- Contact/transport/finalizer/area producer numerical terminal traps were removed, retaining real face-address, negative source-address, unknown wall-kind and other consumed structural errors. Helpers now evaluate and return their material, capillary, impact, damage, area and heat expressions instead of substituting zero result fields. Diagnostic validity remains where supplied; it no longer withholds terminal publication. The bounded `correctedMaximumSpreadFactor` strict inner search was restored exactly from the baseline, including its failure NaN result, expansion/bisection order and successful return formulas. Public impact computation continues from that result into its remaining actual fields. Existing effusivity sentinel/fallback functions and normalized-area/inactive contact skips remain intact.
- Shared wall-interface integration keeps the original zero-age/zero-area skips, stable log1p-minus-x polynomial/log branch and resistance expressions. Numeric early returns and finite-result NaN substitutions no longer intercept an otherwise evaluated scalar expression. Zero nontransient resistance evaluates the native IEEE quotient. Lumped heat preserves the original fixed bisection update order and publishes computed temperature/ledger fields. Nonfinite result diagnostics are not unconditional success.
- Finite-contact relaxation now commits its actual thermal candidate and wall-energy atomic before continuing the original age/rebound/deposition transitions. `publishParticleThermalHeatImpl` gained the explicit `TerminalPublication` template parameter, default false. Existing strict callers retain their original early refusal and finite successful arithmetic. Only `publishFiniteWallThermalHeat` opts into terminal carry publication, using the same double temperature/residual arithmetic and accepted-heat clamps; it publishes the computed wall energy even when its diagnostic validity is false. The particle enthalpy residual remains double and is not removed. No physical float storage was introduced.
- Pressure/packing enabled `dt==0` is a successful identity with no launch, avoiding introduction of `1/dt` or `1/(dt*dt)` work for zero physical time. Nonfinite time no longer causes a host preflight refusal. Disabled/no-particle branches, negative-time path, native launch order and all actual CUDA error handling remain.
- Reduction-task capacity labels and post-write local-task-count equality no longer trap real descriptor materialization. Empty/reversed ranges can be represented; normal task consumers' existing empty loops apply. Negative descriptor addresses remain errors. Payload gathers no longer use the supplied capacity label to reject an otherwise backed source index; actual primary copy remains unchanged. Selected-count clamps and real cell-address checks remain. Tests no longer execute the old length-one/index-one OOB fixtures: all consumed source backing in replacement metadata cases is large enough and the actual primary-copy header is used.
- Automatic scheduling no longer refuses solely because `nCells<1`, including non-inspection calls which consume no cell data. The existing zero modulo-divisor and zero block checks remain for actual integer/launch arithmetic. Real CUDA failure paths remain. No new gate was added.

Classification correction: `clearColdWallParticleState.cuh` already contained only pointer/backing checks at inspection time. It needed no numerical edit. Cold 1D/2D algorithms and their retry/float-profile/double-carry handling are outside this worker's patch and separately owned.

## Cost and limits

Source-level changes add no heap/CUDA allocation, copy, synchronization, persistent state field, new launch or independent scan. Existing finite branch math and RNG/atomic order remain. Removed predicates reduce preflight/terminal checks; extended exceptional arithmetic may perform additional work that the old path never completed. Zero-time pressure/packing now emits no launch. These are source observations, not measured GPU speedup or register/occupancy assertions. Supplied metadata is not an allocation proof: callers still must provide full actual backing. Physical NaN/Inf values can now reach native published output by design; this patch does not promise a finite answer for nonfinite arithmetic.
